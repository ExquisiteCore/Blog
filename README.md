# blog

**本项目是 EC 的个小站**

## 简介

一个简单的个人网站采用前后端分离架构

前端使用 Nextjs + React + TypeScript + shadcnui + Tailwind CSS 开发

后端使用 Rust + Axum + Sqlx

数据库使用 postgresql
